# Glossar

Ergänzen, sobald Begriffe geklärt sind. Herkunft angeben (Quelle oder Frage-ID).

| Begriff | Bedeutung | Herkunft |
|---|---|---|
| NAV | Microsoft Dynamics NAV (Altsystem) | – |
| BC | Microsoft Dynamics 365 Business Central (Zielsystem) | – |
| Code-Tabelle | Stammtabelle mit Primärschlüssel vom Typ Code, auf die andere Tabellen per Tabellenrelation verweisen | – |
| Gebuchte Posten / Belege | unveränderliche Buchungsdaten in NAV, die auf Codes verweisen | – |
| Crosswalk | Zuordnungstabelle alter Code → neuer Code mit Begründung | dieses Projekt |
| SD | Smart Delivery | Beschreibung Code SD (Hauptreklamationsgründe) |
| PD | Premium Delivery | Beschreibung Code PD (Hauptreklamationsgründe) |
| ASV | Anschlussvertrag / neues Gerät / SD | Beschreibung Code ASV |
| Sol-Center | Solution Center | Beschreibung Code SOLCENTER |
| CR | Creditreform | Beschreibung Abwartengrund CR |
| Fibu | Finanzbuchhaltung | Notiz Abwartengründe F10 |
